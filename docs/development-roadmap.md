# 开发路线图

以 `product-requirements.md` 为 V1 需求基线。各阶段完成后在此更新状态。

当前：**1.0.8 开发版**。支持本地卡牌资料、构筑与卡组管理，设置中可选择 Kardsplayer（默认）或 KARDS 官方来源手动获取并核对卡牌数据。新增总部卡图/详情、按主国筛选的总部选择、临时专属桌布，以及由 JSON 清单管理的卡背和桌布资源。尚未完成全部 V1 功能。验证记录见 `development-status.md`。
