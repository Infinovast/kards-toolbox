# KARDS Toolbox（KARDS 工具箱）V1 需求

## 目标

整合 `Kards-Deck-Collector`、`kards-image-tool` 和 `koishi-plugin-kardsman` 的核心能力，提供个人使用的 Windows 桌面应用。卡牌目录、卡组和设置以本地数据为主；应用联网只用于用户主动更新牌库、按需取得卡图和英文直检。

## 用户与平台

- 主要用户：个人玩家，单机使用。
- 目标平台：Windows 桌面应用。
- 主导航：侧边栏上部仅保留“卡组”和“卡牌”，底部竖排“桌布”“设置”，设置在最下面；构筑是编辑卡组时进入的子页面，保存更改后返回卡组列表。
- 界面：中文；卡牌标题和规则文本可切换语言。
- 数据：卡组、合集、设置及缓存保存在本机。

## 功能清单

### 1. 卡牌资料库

- 浏览本地卡牌目录及卡牌详情，包括名称、文本、阵营、类型、费用、稀有度、扩展包和状态。
- 搜索多语言卡名与卡牌文本；按阵营、类型、费用、稀有度、扩展包和状态筛选。
- 卡牌内容支持多语言切换。
- 历史版本只改变卡图；卡牌文字和属性以当前本地目录为准。
- 当前目录没有所选语言/版本的缓存卡图时，在显示卡牌时下载并保存到本地缓存。

### 2. 卡组构筑

- 搜索、筛选卡牌，加入卡组、调整数量和移除卡牌。
- 筛选栏仅含文字搜索、构筑规则、类型、费用、稀有度、扩展包和状态，筛选语义与卡牌库共用。主盟国与卡组码导入位于右侧卡组区。
- 仅显示当前主国的卡牌和盟国非精英卡；排除衍生/特殊形态卡及其他阵营，主盟国相同时保留主国精英。预备卡可通过状态筛选查看；自定义规则不扩大展示卡池。已有及导入卡组的其他卡牌不自动删除。
- 构筑卡图不再额外显示下方名称，保留完整卡面、无障碍名称、悬停提示与稀有度数量方块。
- 内置标准构筑、竞技场及可配置的自定义规则集。
- 根据规则集提示卡组张数、卡牌数量、阵营和可用卡池等问题；校验结果不阻止保存或导出。
- 导入/导出 KARDS 卡组码，支持二维码导入与导出。
- 完全在本机生成并导出卡组图片。
- 构筑与主页共用图片预览及下载流程；预览使用当前构筑，即使尚未保存，关闭后异步结果不得重新打开弹窗。

### 3. 卡组管理

- 保存、重命名、收藏、排序及搜索卡组；支持收藏夹、标签和备注。
- 收藏夹以卡组列表内的可折叠分组显示；提供显示开关，默认关闭并保留用户选择。未归类的卡组单独显示。
- 右上角“关于”页展示中英文名称、版本、项目来源和非官方声明。
- 支持主国、盟国、标签等筛选。
- 备份和恢复用户数据、卡组图片缓存、自定义卡面和桌布。
- 卡牌目录及普通卡图缓存独立于用户备份。

### 4. 卡牌查询

- 支持中文和英文卡名查询。
- 可联网探测本地目录未收录的官方卡图，以及同名变体和老兵形态；结果使用后缓存。
- 展示卡牌详情及可用卡图版本。

### 5. 数据同步

- 随包初始化离线牌库；在全宽设置页手动获取官方最新数据，离开页面后获取继续，支持取消。
- 完整分页获取后按卡牌编号比较新增、修改和移除，可搜索、筛选、分页展开逐字段及多语言差异；即使总数相同，也检查文字和属性变化。
- 获取仅保存候选快照；用户核对后主动应用更新。存在移除时额外确认，保留用户卡组码和携带数量，缺失卡显示编号。
- 应用前保留上次快照，可回退；获取、校验或写入失败保留当前已应用数据。
- 展示获取进度、结果和最近获取/应用时间。卡牌数据与用户备份、普通卡图缓存独立，不随数据更新下载、清空或替换卡图。
- V1 后续补齐按 ID 缺失卡牌补全。使用中发现缺卡时先提示，由用户主动选择补全。

### 6. 娱乐功能

- 模拟官方卡包。
- 支持使用筛选条件构造自定义卡池进行开包模拟。
- 从本地卡牌目录随机抽卡。

### 7. 自定义与设置

- 支持修正已有卡面、上传专属总部/补位卡面和管理桌布。
- 支持深色/浅色主题、配色、界面缩放等外观设置。
- 设置使用全宽页面，外观自动保存；支持保存并返回来源页面和 Esc 返回。
- 卡牌具备 hover 与键盘焦点反馈，所有按钮提供悬停反馈；扩展 Enter 确定、Ctrl+Enter 保存和 Esc 关闭/返回，保留多行输入和中文输入法行为。
- V1 不提供自定义卡牌或阵营创作。

## 约束与范围

- 牌库同步不会在后台静默进行，也不会因普通卡图缓存操作触发牌库更新。
- 缺少所选语言或版本的卡图时，卡图请求可联网并自动缓存。
- 卡组规则违规默认只提示；卡组仍可保存、复制代码和生成图片。
- 卡组图片完全本地渲染，不依赖 KAPI 或其他在线图片生成服务。
- V1 桌面应用不包含 Koishi 聊天机器人命令。
- KARDS 游戏名称、卡牌数据和卡图属于各自权利人；项目遵循参考项目记录的社区内容政策及非官方声明。

## 验收标准

- Windows 桌面开发版本可启动，牌库首次载入不需要网络。
- 用户可以按确认的筛选项查找卡牌，并切换语言和卡图版本；已缓存卡图可离线显示。
- 用户可以构筑、校验、保存及重新打开卡组，并完成卡组码导入/导出。
- 用户数据可备份、恢复；恢复操作不覆盖独立维护的牌库数据。
- 不执行自动牌库更新；所有牌库更新由用户操作触发。
- 获取与应用分离；应用前能核对新增/修改/移除及逐字段差异，应用后可回退，用户卡组与卡图缓存保留。
- 卡组图片可在断网状态下本地生成。

## 项目来源与复用方向

- Deck Collector：Electron 桌面壳、卡组与合集管理、IndexedDB 持久化、备份、主题与桌布。
- KARDS 军械库：卡牌目录、筛选与详情、卡组构筑、卡组码、二维码、卡牌变体探测、开包模拟和 Canvas 渲染。
- Koishi Kardsman：卡牌 GraphQL 数据同步、增量更新、缺卡补全、本地卡图维护及 Sharp 渲染。

实现整合时以一个共享卡牌模型和本地存储目录为准，不直接依赖三个项目各自的运行环境。

## 0.3.2 交互补充

- 全部原生下拉框替换为主题一致的自定义选择框。阵营、类型、费用、稀有度支持多选点亮；同组并集、跨组交集，清空恢复不限；扩展包为单选。
- 阵营为国家图标加名称，中立使用黑色白边菱形；类型为图标加本地化名称；费用仅显示带白色矩形边框的 0K–7K+；稀有度仅显示图标；扩展包图标/顺序参考官方收藏页，中文卡牌内容语言显示中文名称。图标随软件离线分发。
- 卡组右栏改为与卡牌详情类似的非模态悬浮层，可通过关闭按钮或 Esc 完全隐藏。打开/关闭不改变卡组网格、列数或收藏夹布局；单击预览、双击编辑、原有管理操作继续可用。
- 选择框支持键盘导航和 IME，Esc 优先关闭选项/模态窗/内部编辑，再关闭外层详情。最小 980×640 窗口内弹层可达，选择层不被 overflow 裁切。本轮跳过截图与读图测试。
