# 0.1.0 开发记录

日期：2026-10-25。需求基线见 [product-requirements.md](product-requirements.md)，剩余工作见 [development-roadmap.md](development-roadmap.md)。

## 本轮交付

建立根级 Electron + React 工程，复用 Deck Collector 的桌面壳和管理界面，并接入军械库的 1,646 条多语言快照。完成本地查牌、构筑、卡组码、规则提示、保存/继续编辑、备注、离线图片、用户备份恢复的一条完整流程。

新增共享卡牌、卡组码、校验和缓存模块；资料库提供阵营、类型、费用、稀有度、扩展包和状态筛选。卡图按语言/版本独立缓存，历史选择不改变当前卡牌属性。构筑支持标准/竞技场/自定义规则和自动保存草稿，未知卡保留编号并提示手动更新。

卡组图改为本机 Canvas 生成，移除原来的在线出图服务、远程配置及 TLS 绕过。使用已缓存的简中 v54 图片；缺图时仍生成文字占位。备份包含卡组、合集、设置、桌布、草稿及卡组图缓存，排除普通卡图缓存。

Windows 可运行目录：`release/win-unpacked/`，主程序 `KARDS Local Arsenal.exe`。保留整个目录一起使用；本轮尚未验证 NSIS 安装包或单文件便携 EXE。

ZIP 开发包：`release/KARDS Local Arsenal-0.1.0-win.zip`，解压后运行其中的 EXE，无需 Node.js。

界面复核指出的三项问题均已修正：保存的卡组使用可键盘操作的原生按钮；构筑状态文字在浅色主题使用较深前景色（默认面板对比度 5.03:1，输入底色上 5.66:1）；备注固定三行，长内容内部滚动，避免拉伸后挤出操作。离线流程新增键盘选择与备注尺寸核验，浅色构筑页另行截图检查。

设计记录见根目录 `DESIGN.md` 和 `.impeccable/design.json`。它们提取当前主题及组件，不改变原项目视觉风格。初次独立复核由审阅代理完成；后续代理工具不可用，按技能的内联替代流程核验三项修正，核验范围不等于对全部继承界面的全面审计。

测试脚本使用独立配置目录；桌面测试结束清理其临时用户目录。系统文件对话框在测试中被替换为固定文件路径，实际备份仍由 Electron IPC 读写磁盘。下载卡图的线上可用性未作为离线验收条件，失败时应显示占位。

## 已知范围与后续

- 0.1.0 是第一开发里程碑，二维码、手动同步、英文联网直检、变体/老兵探测、开包/随机抽卡、单卡修正及总部卡面尚未完成。
- 牌库是参考仓库 v54 快照，不保证等于当日线上游戏；当前不能通过应用更新。
- 本地 PNG 使用固定的简中 v54 缓存，暂未绘制总部图或二维码。图库语言/历史选择尚不传入 PNG 渲染参数。
- 标准与竞技场规则是本地辅助预设，竞技场不含选秀流程/活动规则；不合法卡组允许保存和导出，游戏是否接受以实际规则为准。
- 沿用的卡组搜索目前按名称匹配、排序以收藏优先为主，后续补齐更完整的搜索和排序选项。
- 源项目大体积卡图未复制到成品；桌面开发与打包版 origin 独立，可用用户备份迁移数据。
