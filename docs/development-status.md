# 0.2.1 开发记录

日期：2026-10-26。需求基线见 [product-requirements.md](product-requirements.md)，剩余工作见 [development-roadmap.md](development-roadmap.md)。

## 本轮交付

在 0.2.0 基础上完成六项导航与命名调整，保留此前九项界面与本地工作流改进。复用 Deck Collector 的桌面壳和管理界面，并接入军械库的 1,646 条多语言快照。完成本地查牌、构筑、卡组码、规则提示、保存/继续编辑、备注、离线图片、用户备份恢复的一条完整流程。

应用名称统一为 KARDS Toolbox（KARDS 工具箱），同步窗口标题、包名、EXE、备份文件名、元信息和文档。左侧仅保留“卡组”和“卡牌”；原合集在卡组列表中以可展开收藏夹展示，开关默认关闭、保存偏好，并单独显示未归类卡组。收藏夹支持创建、重命名、置顶、添加/移出卡组和删除；删除收藏夹保留卡组。

构筑不再有独立入口，仅由卡组编辑进入，保存更改后退出；编辑中导入卡组码会更新原卡组，不再意外创建副本。卡牌库网格/详情及构筑网格/清单/提示区域均使用主题细滚动条。右上角无响应的人头按钮替换为“关于”，展示名称、版本、来源和非官方声明，并能返回来源页面。

改名会识别旧版有 IndexedDB 数据的用户目录，避免数据看似丢失；显式 `--user-data-dir` 仍优先。保留安装应用 ID 兼容性。新备份使用 `kards-toolbox`，继续接受 `kards-local-tool` 和 `kards-deck-collector`。

新增共享卡牌、卡组码、校验和缓存模块；资料库提供阵营、类型、费用、稀有度、扩展包和状态筛选。卡图按语言/版本独立缓存，历史选择不改变当前卡牌属性。构筑支持标准/竞技场/自定义规则和自动保存草稿，未知卡保留编号并提示手动更新。

资料库新增按当前筛选批量缓存卡图，任务队列独立于页面生命周期，支持大批量确认、进度/速度/预计时间、失败重试和已缓存跳过。详情使用覆盖层，不挤压网格；资料库与构筑卡图保留完整边缘，构筑使用稀有度方块显示携带数量。卡组列表支持单击预览清单、双击编辑。

卡组图改为 Kardsman 风格的本机 Sharp 十列组合管线，使用 2304 宽画布、白色标志、稀有度统计、重复卡牌和总部槽位；开发浏览器仍有同构 Canvas 预览。备份包含卡组、合集、设置、桌布、草稿及卡组图缓存，排除普通卡图缓存。

所有侧栏和悬浮窗统一毛玻璃样式，桌布覆盖 header 下完整工作区；主题切换时同步更新窗口标题栏/任务栏图标，暗色使用白色标志。对话框支持 Enter 确定、Esc 关闭/取消、焦点循环和关闭后的焦点恢复。

Windows 可运行目录：`release/win-unpacked/`，主程序 `KARDS Toolbox.exe`。保留整个目录一起使用；NSIS/单文件便携目标仍不作为本轮验收范围。

ZIP 开发包：`release/KARDS Toolbox-0.2.1-win.zip`，解压后运行其中的 EXE，无需 Node.js。

界面复核指出的三项问题均已修正：保存的卡组使用可键盘操作的原生按钮；构筑状态文字在浅色主题使用较深前景色（默认面板对比度 5.03:1，输入底色上 5.66:1）；备注固定三行，长内容内部滚动，避免拉伸后挤出操作。离线流程新增键盘选择与备注尺寸核验，浅色构筑页另行截图检查。

设计记录见根目录 `DESIGN.md` 和 `.impeccable/design.json`。它们提取当前主题及组件，不改变原项目视觉风格。初次独立复核由审阅代理完成；后续代理工具不可用，按技能的内联替代流程核验三项修正，核验范围不等于对全部继承界面的全面审计。

测试脚本使用独立配置目录；桌面测试结束清理其临时用户目录。系统文件对话框在测试中被替换为固定文件路径，实际备份仍由 Electron IPC 读写磁盘。下载卡图的线上可用性未作为离线验收条件，失败时应显示占位。

## 已知范围与后续

- 0.2.1 是导航与命名调整开发版，二维码、手动同步、英文联网直检、变体/老兵探测、开包/随机抽卡、单卡修正及总部卡面尚未完成。
- 牌库是参考仓库 v54 快照，不保证等于当日线上游戏；当前不能通过应用更新。
- 本地 PNG 读取当前本地缓存并绘制 Kardsman 风格总部槽位；尚未绘制二维码。图库语言/历史选择尚不传入 PNG 渲染参数。
- 标准与竞技场规则是本地辅助预设，竞技场不含选秀流程/活动规则；不合法卡组允许保存和导出，游戏是否接受以实际规则为准。
- 沿用的卡组搜索目前按名称匹配、排序以收藏优先为主，后续补齐更完整的搜索和排序选项。
- 源项目大体积卡图未复制到成品；桌面开发与打包版 origin 独立，可用用户备份迁移数据。
