## 0.3.1 本轮交付

- 构筑筛选栏仅保留文字搜索、构筑规则、类型、费用、稀有度、扩展包和状态，与资料库共用筛选函数，包括 7+ 费用、多语言文本与 description 回退搜索。
- 构筑仅展示主国卡和盟国非精英卡，排除其他阵营、中立、衍生与特殊形态；主盟国相同时保留主国精英。自定义规则不扩大展示卡池，已有/导入的卡组条目不自动删除。主盟国及卡组码导入移至右侧，滚动内容与底部主操作分离。
- 去除构筑卡图下的名称条，保留完整图片、无障碍名称、悬停提示和稀有度数量方块。构筑图片导出复用主页同一预览，使用当前未保存的名称与卡组码，确认后下载；关闭后忽略迟到结果。
- 卡牌 hover 和焦点轻微内缩提亮；按钮使用统一基础 hover，既有局部效果继续生效，禁用按钮不触发。
- 扩展 Enter/Esc：构筑 Ctrl+Enter 保存、Esc 返回，搜索/导入框先清空；Enter 导入、Shift+Enter 换行；资料库 Enter 聚焦首卡后可继续 Enter 查看，Esc 关闭详情/重置筛选；设置 Ctrl+Enter/Esc 返回，关于页 Esc 返回；标签与卡背行内编辑处理 Enter/Esc 并保护 IME。对话框支持焦点外 Esc 关闭，异步禁用触发按钮后仍能恢复焦点。

## 本轮交付

在 0.2.1 基础上，将桌布和设置入口竖排置于左栏底部、设置在最下方；设置由弹出层改为全宽页面，保留外观与用户备份功能，支持保存并返回和 Esc 返回。

新增手动官方牌库更新：获取 → 预览新旧差异 → 应用更新，并支持回退上次快照。参考 Kardsman 的 GraphQL 分页实现，完整获取后逐字段比较，避免同数量的费用/文本修改被跳过。差异包括新增、修改、移除及多语言，支持搜索、筛选和分页。任务切换页面后继续，可取消；HTTP/GraphQL、分页或数据校验失败时不替换当前牌库。

候选、当前和上次快照通过独立 IndexedDB 键原子保存，应用失败允许重试。应用或回退后资料库、构筑和卡组规则提示使用对应数据，用户卡组码、数量、收藏与备注保留；远端移除卡牌需要额外确认，未知卡显示编号。未带入源项目的图片同步逻辑，卡图缓存保持独立，牌库快照也不进入用户备份。

2026-10-26 通过浏览器实际获取官方接口全部 17 页、共 1,646 张，与随包资料对比为新增 0 / 修改 0 / 移除 0；未应用测试数据。记录见 `test-results/card-sync/live-preview.json`，真实接口截图见 `test-results/card-sync/live-official-preview.png`。新版打包 EXE 的实际 preload/IPC/Chromium 网络请求也成功取得第一页 100 张、总数 1,646，未应用，记录见 `test-results/card-sync/live-native.json`。线上结果仅代表该次核对，不保证未来数据不变。

以下保留此前已完成的导航与本地工作流：复用 Deck Collector 桌面壳和管理界面，接入军械库的 1,646 条多语言快照，完成本地查牌、构筑、卡组码、规则提示、保存/编辑、备注、离线图片及备份恢复。

应用名称统一为 KARDS Toolbox（KARDS 工具箱），同步窗口标题、包名、EXE、备份文件名、元信息和文档。左侧主入口为“卡组”和“卡牌”；原合集在卡组列表中以可展开收藏夹展示，开关默认关闭、保存偏好，并单独显示未归类卡组。收藏夹支持创建、重命名、置顶、添加/移出卡组和删除；删除收藏夹保留卡组。

构筑不再有独立入口，仅由卡组编辑进入，保存更改后退出；编辑中导入卡组码会更新原卡组，不再意外创建副本。卡牌库网格/详情及构筑网格/清单/提示区域均使用主题细滚动条。右上角无响应的人头按钮替换为“关于”，展示名称、版本、来源和非官方声明，并能返回来源页面。

改名会识别旧版有 IndexedDB 数据的用户目录，避免数据看似丢失；显式 `--user-data-dir` 仍优先。保留安装应用 ID 兼容性。新备份使用 `kards-toolbox`，继续接受 `kards-local-tool` 和 `kards-deck-collector`。

新增共享卡牌、卡组码、校验和缓存模块；资料库提供阵营、类型、费用、稀有度、扩展包和状态筛选。卡图按语言/版本独立缓存，历史选择不改变当前卡牌属性。构筑支持标准/竞技场/自定义规则和自动保存草稿，未知卡保留编号并提示手动更新。

资料库新增按当前筛选批量缓存卡图，任务队列独立于页面生命周期，支持大批量确认、进度/速度/预计时间、失败重试和已缓存跳过。详情使用覆盖层，不挤压网格；资料库与构筑卡图保留完整边缘，构筑使用稀有度方块显示携带数量。卡组列表支持单击预览清单、双击编辑。

卡组图改为 Kardsman 风格的本机 Sharp 十列组合管线，使用 2304 宽画布、白色标志、稀有度统计、重复卡牌和总部槽位；开发浏览器仍有同构 Canvas 预览。备份包含卡组、合集、设置、桌布、草稿及卡组图缓存，排除普通卡图缓存。

所有侧栏和悬浮窗统一毛玻璃样式，桌布覆盖 header 下完整工作区；主题切换时同步更新窗口标题栏/任务栏图标，暗色使用白色标志。对话框支持 Enter 确定、Esc 关闭/取消、焦点循环和关闭后的焦点恢复。

Windows 可运行目录：`release/0.3.0/win-unpacked/`，主程序 `KARDS Toolbox.exe`。保留整个目录一起使用；NSIS/单文件便携目标仍不作为本轮验收范围。旧程序占用原打包目录，本轮另用版本目录，未关闭用户正在运行的旧实例。

ZIP 开发包：`release/0.3.0/KARDS Toolbox-0.3.0-win.zip`，解压后运行其中的 EXE，无需 Node.js。

## 已知范围与后续

- 0.3.0 是手动牌库更新开发版；二维码、按 ID 缺卡补全、英文联网直检、变体/老兵探测、开包/随机抽卡、单卡修正及总部卡面尚未完成。
- 首发牌库为参考仓库 v54 快照；可通过设置手动核对并应用官方更新，不做启动自动同步，也不自动刷新卡图。
- 本地 PNG 读取当前本地缓存并绘制 Kardsman 风格总部槽位；尚未绘制二维码。图库语言/历史选择尚不传入 PNG 渲染参数。
- 标准与竞技场规则是本地辅助预设，竞技场不含选秀流程/活动规则；不合法卡组允许保存和导出，游戏是否接受以实际规则为准。
- 沿用的卡组搜索目前按名称匹配、排序以收藏优先为主，后续补齐更完整的搜索和排序选项。
- 源项目大体积卡图未复制到成品；桌面开发与打包版 origin 独立，可用用户备份迁移数据。
